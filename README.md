# Keystone Lite Dental: free one-page dentist website template

A fast, accessible, single-page HTML/CSS site for a dental practice: family, cosmetic or
emergency dentistry, orthodontics, or any clinic that books patients locally. No framework,
no build step: open `index.html`, change the words, upload the folder.

**Live preview:** https://stephen-psaradellis.github.io/keystone-lite-dental/

Running a plumbing, HVAC or electrical business instead? The same layout with a trades
theme is [Keystone Lite](https://github.com/Stephen-Psaradellis/keystone-lite).
A house cleaning or maid service? [Keystone Lite Cleaning](https://github.com/Stephen-Psaradellis/keystone-lite-cleaning).

## What you get (free, MIT)

- One home page with hero, treatments, first visit, why us, same-day emergency banner,
  patient reviews, location and parking, and a final booking call to action
- Sticky call bar on phones, so a patient is one tap from ringing the front desk
- Light and dark mode (follows the visitor's system, plus a header toggle)
- Dentist (LocalBusiness) JSON-LD, Open Graph and Twitter Card tags, canonical URL
- Accessibility basics: skip link, landmarks, visible focus, reduced-motion support
- Retheme the whole site by editing the variables at the top of `assets/css/style.css`
- One small script (`assets/js/main.js`) for the mobile menu and the dark-mode toggle

## Quick start

1. Download this repository (Code > Download ZIP) and unzip it.
2. Open `index.html` and replace the business name, phone number (`tel:` links too),
   address, hours, services and reviews with your own.
3. Update the JSON-LD block in `<head>` with the same details, and point the
   canonical / Open Graph URLs at your domain.
4. Upload the folder to any static host: GitHub Pages, Netlify, Cloudflare Pages or
   plain shared hosting.
